# Form Management System

A React + Vite application for managing personal information through an interactive form.

## ✨ Features

* Personal information form
* Form validation
* Email and phone number validation
* Country and gender selection
* Skills and hobbies selection
* 50-word limit with live word counter
* Add, view, edit, and delete records
* Reset form functionality
* Local Storage data management

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Local Storage
* Vite
